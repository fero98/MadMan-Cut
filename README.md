# MadMan Cut

MadMan Cut is a Windows video editor with a Czech interface, timeline editing,
captions and optional AI-assisted workflows. This is an alpha test version.

Windows builds and signed updates are published on the [MadMan Cut releases page](https://github.com/fero98/MadMan-Cut/releases).
The first version with the updater must be installed manually; later updates are offered in the app.
An AI agent requires its compatible command-line tool and a separately configured account.
